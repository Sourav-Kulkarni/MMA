# Weapons

Kali is taught weapon-first. The movements, footwork, and principles you learn with a stick translate directly to blade, empty hand, and other weapons.

| Page | Weapon | Notes |
|---|---|---|
| [Single Stick](single-stick.md) | Olisi / Baston | Primary weapon. Start here. |
| [Double Stick](double-stick.md) | Doble Olisi | Builds ambidexterity and sinawali patterns |
| [Knife (Daga)](knife.md) | Daga | Edge awareness, grip, close-range application |

---

!!! note "Equipment"
    For training, use **rattan sticks** (about 28 inches, 3/4 inch diameter is standard). Rattan is forgiving on impact, won't shatter, and is inexpensive. Upgrade to hardwood or aluminium only for forms/demonstrations.
